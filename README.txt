# NUMBER MISSION

Visual Studio Codeで動かせる、HTML/CSS/JavaScriptだけのゲームです。

## 実行方法

1. このフォルダをVisual Studio Codeで開く
2. `index.html` を開く
3. VS CodeのLive Serverを使う場合は「Open with Live Server」
4. または `index.html` をブラウザで直接開く

## ゲームの流れ

STAGE 1
↓
スタート
↓
ルール
↓
次へ
↓
クリア条件
↓
START
↓
3 → 2 → 1
↓
MISSION 1
↓
MISSION 2
↓
MISSION 3
↓
CLEAR

90秒を超えると即FAILEDになります。

## 仕様

- 5つのMISSIONを90秒以内にクリア
- 誤答してもペナルティなし
- 誤答しても残り時間は減らない
- アルファベット入力欄あり
- 画面上のアルファベットキーボードでも入力可能
- 3、2、1のカウントダウン後にタイマー開始
- MISSION 3正解時点で120秒以内ならCLEAR
- 120秒になった時点でFAILED

## 問題を変更する

`script.js` の最初にある `missions` を変更してください。

例：

{ number: "53", answer: "A" }

なら、「53」を見つけたときに「A」を入力すると正解です。

現在はスクリーンショットに合わせて、MISSION 1～5で
53 → A
163 → B
59 → C
を使う設定にしています。

必要なら `missions` の内容を変更して、好きな問題にできます。


## 効果音

- 正解：明るい「ピン・ポン」風の効果音
- 不正解：低い「ブッ」風の効果音
- 外部の音声ファイルは使用していないので、追加ファイルなしで動きます。
